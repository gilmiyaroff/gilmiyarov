## Структура

- `index.html` — новая версия портфолио (V2).
- `assets/portfolio-v2.css` — адаптивный дизайн.
- `assets/portfolio-v2.js` — мобильное меню и появления секций при прокрутке.
- `archive/portfolio-v1-2026-11-16.html` — полный снимок предыдущей страницы до редизайна.
- `og-image.PNG` — изображение превью ссылки.

## Будущие скриншоты

В `index.html` уже помечены HTML-комментариями `FUTURE PROOF SLOT` места для иллюстраций кейсов и продуктов. Когда появятся одобренные к публикации изображения, можно разместить WebP/PNG в `assets/` и включить их в соответствующие блоки.

Не публиковать имена и контакты клиентов, CRM-выгрузки, внутренние финансовые отчёты и скриншоты с персональными данными без согласования.
